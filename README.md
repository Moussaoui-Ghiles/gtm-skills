# GTM skills

Claude Code skills for go-to-market work: finding the right accounts, qualifying them, and getting verified contacts. Each folder is one skill. Copy it into `~/.claude/skills/` (or a project's `.claude/skills/`) and Claude Code picks it up.

| Skill | What it does |
|---|---|
| [linkedin-engagers](linkedin-engagers/) | Turns the people who comment on or react to LinkedIn posts into qualified, verified leads. Labels everyone against your ICP first, so you only pay for buyers' emails. |

Built by [Ghiles Moussaoui](https://www.linkedin.com/in/ghiles-moussaoui-b36218250). MIT licensed.
